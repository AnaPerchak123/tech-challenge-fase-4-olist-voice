# Dados de origem

Fonte: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

Colocar nesta pasta o arquivo `olist_order_reviews_dataset.csv`, obtido na fonte.
O arquivo original é preservado; a preparação gera saídas em `data/processed/`.

O script também aceita o ZIP original por `--input`. Dados brutos não são
versionados. Consultar na fonte as condições de licença e atribuição.
